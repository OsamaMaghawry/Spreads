## This cycle's asks (top five, ranked by exposure)

**1. Primary-action colour still differs by screen (W36 #1/#5).**
Surfaces: every trader-facing app screen. Scanner H1 icon is
`text-emerald-600` (`Scanner.jsx:158`) while the same page's headings use
`text-dm-text`; primary buttons are emerald (`ConfirmSubmit.jsx`,
`AccountForm.jsx`, `ExportPdfButton.jsx`) vs `dm-accent` on nav/Admin vs
near-black on Login. Green therefore means "go" and "gain" on one screen.
**Fix:** point primary buttons and decorative icons at `dm-accent`; leave emerald for P/L and connection state only.

**2. Red/loss is still five reds (W36 #4).**
Surfaces: app P/L, landing, PDF. `rose-*` remains the loss colour across the
app (60 files); `dm-negative` is used at 2 call sites; landing `--rose: #B4485C`
(`site.css`) and PDF banner `rgb(180, 72, 92)` match each other, not
`dm-negative` `#993C1D`.
**Fix:** map `rose-*` loss/risk usages, landing `--rose` and the PDF banner to `dm-negative`.

**3. One feature, three names, including on the PDF that leaves the product (W36 #3).**
Surfaces: Analysis page, exported PDF. H1 reads "Analysis"; the PDF title prop
reads `"… — Performance Analysis"` (`AccountAnalysis.jsx:553`); disclosure and PDF
footer read `"DeltaMint — economic performance report."`
(`AnalysisDisclosure.jsx:25`, `ExportPdfButton.jsx:185`). brand.md lists
"performance page" as a forbidden name.
**Fix:** change the title prop to `` `${name} — Analysis` ``; footer wording only after desk-editor/compliance-gate clear it (hand-off).

**4. Emoji severity dots in customer email (W36 #7).**
Surfaces: daily digest and position-watch alerts (every digest recipient).
`watchReport.ts` `dot()` and `positionWatch/index.ts` `sev()` render 🔴/🟠/⚪;
no other surface uses emoji, and the red dot is red used as decoration-by-glyph.
**Fix:** replace with the words critical / warning / info in `dm-negative` / `dm-warning` / `dm-sub`, from one shared helper.

**5. Sign-up email is off-palette (W36 #10).**
Surface: `confirm-signup.html` — every new user's first email. Link colour
`#4f46e5` (Tailwind indigo) vs `dm-accent` `#534AB7`; text `#0f172a`/`#475569`/`#94a3b8` vs `dm-text` `#201B3A`/`dm-sub` `#6A6294`.
**Fix:** swap those four hexes for the `dm` values.
