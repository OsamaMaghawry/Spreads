## What shipped this week

Plain English, from `docs/ops/shipped.md` and this week's ledgers:

- **New logo.** A drawn delta-glyph wordmark, consistent across the app, drawer, auth screen and the marketing site.
- **Covered calls are priced correctly now** — a call covered by a long call, not just shares, values right; a ticker whose cover is already spoken for is flagged instead of hidden, and the scanner stops suggesting you sell it again.
- **The whole-market scanner now actually scans the whole market.** It was silently capped at the first 4,000 of 12,647 tickers alphabetically — missing NVDA, TSLA and SPY entirely. Now paginated up to 20,000.
- **Cash-secured-put and covered-call scans stopped coming back empty by design** — the old 15% return floor was uncleareable; it's 0% by default now, and presets save for these strategies too.
- **Scanner earnings messaging cleaned up** — no more confusing "No earnings date" badge; a real earnings warning now shows in the trade ticket, and "unknown coverage" no longer reads the same as "none scheduled."
- **Analysis counts every closed trade now**, including single-leg ones that used to be silently excluded from the rollup.
- **A redesigned Analysis page** (result and chart first, caveats attached to the number they affect) is built and live on staging behind a flag.
- **The blog's broken-image bug is patched.** The publisher only ever wrote diagram images to `main`, never to staging, so the landing site's deploy gate silently refused every landing deploy since 14 September — burying three posts' images and the new logo. The underlying cause (still `main`-only writes) is not yet fixed, so the same trap can reopen on the next diagram post.
- **Unfinished broker evaluation work (SnapTrade/Tradier) is now isolated** behind a build flag so it can no longer block small production fixes from shipping.
- **Internal failure alerts (failed blog publish, equity-history drift) now route to `agents@deltamint.app`** instead of the customer-facing address — see decision 8 below.
