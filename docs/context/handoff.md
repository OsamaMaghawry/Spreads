## What DeltaMint is

A browser tool for self-directed options traders. It pairs option legs back
into the positions that created them, and shows each position's real credit,
risk, break-evens and value. It holds no money, executes nothing itself and
gives no advice. Revenue is a flat subscription; the standing proposal is
Paper free and Live $29/$290 (`docs/product/pricing.md`).

- **Dashboard app:** dashboard.deltamint.app, React + Vite on Cloudflare
  Workers. Broker calls happen only in Supabase edge functions.
- **Brokers:** Alpaca (OAuth, see AGENTS.md). SnapTrade and Tradier are built
  for evaluation and wait on the owner (`docs/ops/queue.md`).
- **Trading terminal:** admin-only, on staging. It has the chart, ticket,
  hotkeys, several accounts at once, scanner, gamma, P/L and Playbook. The
  detail is in `docs/context/terminal-handoff.md`.
- **Marketing site and blog:** deltamint.app (`landing/`, a Cloudflare Worker),
  with posts from `content/blog/`.
- **Claude connector:** the `mcp` edge function, read-only tools.
- **Emails:** through Brevo (`sendDigest`), plus the weekly digest and position
  alerts (`positionWatch`).
- **The whole product in one file:** `docs/product-context.md`. It is
  generated by `npm run context`; never edit it by hand.
