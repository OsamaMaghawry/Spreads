# Research inbox

The owner's drop-box. Screenshots taken while browsing — a competitor's
pricing page, their scanner UI, a review thread, a still from a demo video —
dropped here become first-class **verified** evidence: agents read images
directly.

Name files for what they show: `optionstrat-pricing-2026-08.png`,
`barchart-scanner-filters.png`. Agents also save their own Playwright
captures here under the same convention.

Nothing in this folder is published anywhere, ever. It is working evidence.
